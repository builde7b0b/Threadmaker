## Screenshot Specifications

### Technical Requirements:
- **Resolution**: 1920x1080 or higher
- **Format**: PNG or JPG
- **Quality**: High quality, clear text
- **Annotations**: Add red boxes/circles to highlight key areas
- **Text Overlays**: Include brief explanations where needed

### Content Guidelines:
- **Code Snippets**: Show actual working code, not placeholder text
- **Real Data**: Use actual Stripe prices, database records, etc.
- **Error Handling**: Include examples of error scenarios and solutions
- **Success States**: Show successful operations and positive outcomes

### Visual Style:
- **Consistent Theme**: Use dark/light theme consistently
- **Professional Look**: Clean, organized, easy to read
- **Highlighting**: Use colors to emphasize important parts
- **Annotations**: Add arrows, boxes, or circles to point out key features
